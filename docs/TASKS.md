# 开发任务列表（模块 DAG + 任务卡）

> 组织方式：**下层 22 个模块**（每个 1–2 周，接口冻结、mock 可替、独立 harness，
> 可任意并行）+ **上层 5 个集成里程碑**（串行，验证"接缝"）。
> 不用阶段表，因为阶段表隐含"所有人朝同一个功能前进"，与 1–2 周模块粒度不兼容。

---

## 0. 任务卡的十个字段（缺一不算任务）

| 字段 | 内容 | 判定标准 |
|---|---|---|
| 编号与名称 | `K12 响应算子与伴随求解` | 全局唯一 |
| 目标 | 一句话，可判定 | 不含"优化""改进"这类词 |
| 输入契约 | 数据结构、shape、dtype、可微性 | 引用 `spec/` 的具体小节 |
| 输出契约 | 同上 | 同上 |
| 验收测试 | 公开部分（实现方可见） | 每条都有数值门槛 |
| 封存测试 | 20%，提案方持有，不进仓库 | 按物理情形切分 |
| 性能门槛 | 相对 ref 的时间/带宽 | 附测量协议 |
| 禁止事项 | 不许改的接口/容差/约定 | 明确列出 |
| 交付物 | 代码 + 报告 + 失败卡 | 缺一不算完成 |
| 依赖 | 前置模块编号 | DAG 校验 |

**M0 的意义**：用六周买一个"要不要继续"的答案。它包含三件事——

三件事都不需要 GPU：**在物理与验证都跑通之前，GPU 只会让错误跑得更快。**

## 3. 六张详细任务卡

### K01 契约库

* **目标**：五份 `spec/` 通过评审，且每份都有"失败模式"一节。
* **输入**：ABACUS 源码事实（`docs/ABACUS_FACTS.md`）+ 方案 V2 第 2 章。
* **输出**：`spec/{units,discretization,pseudopotential,occupation,invariants}.md`。
* **验收**：每条约定可被 `contract-check` 解析成断言；`spec/` 的改动触发全量回归。
* **禁止**：不得写"参考 ABACUS"这类不可判定的表述；每个数值容差必须给出来源。
* **交付**：五份文件 + `tests/test_contracts.py`（把约定变成断言）。

### K04 G 壳层与 FFT 盒

* **目标**：`Basis` 的整数指标与 FFT 盒与 ABACUS 逐位相同。
* **输入**：`lattice (3,3)`、`ecut`（Ha）、`density_factor`。
* **输出**：`Basis(miller:int32(nG,3), ecut, fft_shape)`；miller 冻结。
* **验收**：
  1. 同一 `ecutwfc=30 Ry`、同一晶胞，`nG` 与 `nfft` 与 ABACUS 相同；
  2. 盒规则只允许 {2,3,5}（用 7 的算例必须失败）；
  3. UEG 能量与解析值相对误差 < 1e-6；
  4. `shell_margin() > 5%`，否则拒绝进入应力校验集。
* **封存**：一个六方晶胞（各向异性 `|a_i|` 差异 2×）+ 一个斜胞。
* **禁止**：不得用 `7`；不得在求导时重建 miller；不得把 `g2` 缓存成常量。
* **性能**：`make_basis` ≤ 1 ms（nG<500）。

### K07 XC 桥 + 融合 kernel

* **目标**：`energy-only` 接口，势由 AD 生成；生产路径融合成单 kernel。
* **输入**：`rho_r (nfft,) fp64`，libxc ID。
* **输出**：`E_xc`（标量）、`v_xc (nfft,)`。
* **验收**：
  1. 逐点 `v_xc` vs libxc 解析值 < 1e-10；
  2. **驻点性** `‖∂E_var/∂n‖ < 1e-8‖v_eff‖`（抓 `N/Ω` 权重错）；
  3. GGA 的 `−∇·` 项自动出现：局域扰动 `ΔE ≈ ∫v δn`，相对误差随扰幅线性下降；
  4. `∇` 与 `−∇·` 的离散转置：`⟨∇f,v⟩ = −⟨f,∇·v⟩` 到机器精度。
* **封存**：自旋极化 LDA（nspin=2）、meta-GGA 的 τ 依赖、密度含负值邻域（截断行为）。
* **禁止**：不得手写 `−∇·`；不得在 kernel 里用 fp32 累加能量。
* **性能**：单次调用 ≤ 1.2× ref；融合后 DRAM 流量 ≤ 0.7× 未融合。

### K08 非局域投影

* **目标**：`V_NLψ` 及其对 ψ、R、cell 的 VJP，相对误差 < 1e-10。
* **输入**：`ψ (nk,nband,nG) complex`、`β` 由 `(R, cell)` **现场生成**、`D`。
* **输出**：`V_NLψ`；VJP 三元组。
* **验收**：
  1. 与 ref 逐元素 < 1e-10；
  2. 伴随恒等式 `⟨Ax,y⟩=⟨x,Aᵀy⟩` 到机器精度；
  3. 对 R 的 VJP 与中心差分在**三个构型**上一致（平衡、位移 0.05 Å、低对称畸变）。
* **封存**：含 NLCC 的元素、`l=2` 投影、极端形变（±3% 应变）。
* **禁止**：**不得缓存 β 的插值表**；不得改 `Ω^{-1/2}` 的约定。
* **性能**：单次调用 ≤ 1.2× 参考 kernel；批处理 GEMM 次数 ≤ 2。

### K12 响应算子与伴随求解 ★ R3 已修复

* **目标**：`A = I − ∂F/∂n` 的 matvec 与 `Aᵀλ = g` 的求解，使 `dL/dθ` 与
  "重跑 SCF 的有限差分"一致。
* **输入**：收敛态 `SCFState`、损失 `L(state)`。
* **输出**：`λ`、`dL/dθ`。
* **验收（按顺序）**：
  1. **I-15**：`J·δ` vs `(F(n+hδ)−F(n−hδ))/2h`，`corr > 0.999`、`rel < 1e-3`
     （至少 5 个随机 δ，含零均值与非零均值各一）；
  2. `Aᵀλ=g` 的相对残差 < 1e-10；
  3. `dL/dθ` vs FD（重跑 SCF）相对误差 < 1e-3；
  4. 显存不随 SCF 迭代数增长（记录峰值）；
  5. 成本 < 3× 一次 SCF。
* **封存**：金属（σ=0.1 eV，部分占据）、简并构型（对称二聚）、近简并（带隙 1 meV）。
* **禁止**：不得用 `jacfwd/jacrev` 穿过 `eigh`；不得把混合器纳入图；
  不得让 `J` 的口径与 `scf_map` 的截断/占据口径不一致。
* **R3 状态**：解析一阶微扰已在 `nfft=729` 上给出 `corr=1.0000 / rel=8.5e-9`；
  R3-07 用 matrix-free `Aᵀλ=g` 在 `nfft=3375` 上复核，实测
  `corr=0.9999999999994564 / rel=1.140e-6`，门槛仍是
  `corr>0.999 / rel<1e-3`。ΔQ 伴随残差 `2.28e-11`，vs 重跑 SCF FD
  相对误差 `1.65e-5`。ABACUS 外部对照已闭合（固定二进制 `c17cbac9b`）：
  Si/Γ E 差 `0.277 meV/atom`、F `0.593 meV/Å`、σ `0.029 kbar`。
* **性能**：matrix-free GMRES，matvec ≤ 1× 一次 `scf_map`。

### K13 力与应力

* **目标**：`F = −dF_M/dR`、`σ = −(1/Ω)dF_M/dε`（ABACUS `TOTAL-STRESS`
  约定，压缩为正），与有限差分一致。
* **验收**：
  1. 四个构型（平衡、±1% 应变、单原子位移 0.05 Å、低对称畸变）力误差 < 1e-4 eV/Å；
  2. `Σ_I F_I = 0` 到 1e-8；
  3. virial 关系成立；静水压 `B0` 与 Birch–Murnaghan 拟合一致；
  4. 壳层跳变处应力不连续 < 0.1 kbar。
* **封存**：`ecut` 边界附近的构型（壳层刚好跳变）、含 NLCC 体系、金属。
* **禁止**：为力写专门的解析公式（若需要，说明能量图有缺口）。
* **性能**：一次力评估 ≤ 3× 一次能量评估（含伴随）。

## 5. 记分板（每周更新，诊断而非绩效）

| 指标 | 定义 | 目标 |
|---|---|---|
| 一次通过率 | 首次提交即通过全部公开测试的比例 | > 60% |
| 逃逸缺陷率 | 封存集/集成期发现的缺陷 ÷ 总缺陷 | 越低越好 |
| 缺陷密度 | 每千行代码的缺陷数 | 趋势下降 |
| 返工次数 | 同一模块被打回的次数 | < 2 |
| 性能达标率 | 达到任务卡性能门槛的模块比例 | > 85% |
| 周期时间 | 任务卡从开出到验收的天数 | < 15 天 |

**诊断读法**：通过率低 → 任务卡写得含糊；逃逸率高 → 公开测试覆盖不足；
周期时间长 → 依赖没解耦。

## 6. 对抗退化的三个信号

1. 测试通过率接近 100%，但集成期缺陷不断 → 公开测试与真实分布脱节，换提案方。
2. 任务卡越来越长 → 模块粒度失控，拆分到一周内可验收。
3. 轮换后无人能接手 → 知识没文档化，冻结新任务补 ADR。
