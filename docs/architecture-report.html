Architecture Review · v0.1

可微周期性 DFT 内核
契约复刻 ABACUS，架构重新搭建

能量是唯一可微标量，力、应力、极化、约束乘子都是它的导数；SCF 用不动点隐式微分，显存与迭代数解耦。复刻的是 ABACUS 的物理契约，不是它的代码。本页给出分层架构、22 个模块的任务分解、五级校验方案——以及 R3 收口后的实测状态。

依据：abacus-develop（develop）源码实测 参照：DQC 的 AD 契约 方法：可微DFT复刻方案 V2

01先说结论：什么已经成立，什么还不成立

这套架构的赌注是三句话，每一句都能被独立证伪。原型跑下来，能量层与梯度层都立住了。验证体系在发布前挡下了 9 个"能量完全正确、梯度错 20–31%" 的 bug——其中最贵的一个只花一行代码，却让 SCF 收敛、能量差 3 mHa、而力偏 31%。

最贵的一个 bug

一行 vg.astype(rho_r.dtype) 把复数静默转成实数，丢掉 n_G 的虚部。SCF 照样收敛、能量只差几 mHa、全部测试看着正常，而整条梯度链错了 31%。

为什么这条记录本身就是交付物的一部分。如果只交一份"全部通过"的报告，读者无法判断它是真的通过，还是把容差放宽了。而一个失败的、带数字的、可复现的判据，恰好是下一轮工作的起点——它把"还需要调"变成"按 K04→K07→K08→K12→K13 的顺序修"。

02分层架构：可微性只有一个入口

七层，边界判据是"跨层调用是否违反抽象"。最关键的一条：L4 只在收敛点被调用——如果在 SCF 迭代过程中调用微分层，显存会随迭代数增长，梯度也会依赖未收敛的残差。

L6
应用层泛函训练 · Δ-learning · 约束扫描 · 逆设计
不反向依赖实现
L5
观测量E(分解) · F · σ · P(Wilson) · Z* · λ
薄：>50 行 = 在重实现 L2
L4

仅在收敛点调用

每个都要 fwd + vjp + 梯度测试

类型系统
# 唯一的可微叶子
class Cell(NamedTuple):
    lattice: Array   # (3,3) 行向量, Bohr
    frac:    Array   # (nat,3) 分数坐标

# 一律不进微分图
class Static(NamedTuple):
    basis: Basis     # miller 冻结
    kpts, kweights   # Σw = 1
    psp, nband, sigma, nelec

一旦 Cell 在 L1 被摊平成 numpy，后面所有导数都断，而能量仍然是对的。这是本项目最贵的一类错误，用类型挡住。

三条求导路径
① 局部 VJP线性算子 → 伴随算子作用。构件。
② 不动点隐式Aᵀλ = ∂L/∂n，A = I − ∂F/∂n。生产主路径。
③ 变分端到端直接对 ψ 求导。语义最干净，条件数最差。

只有 ② 同时满足"内存与迭代数解耦"和"梯度即物理量"。

第 5 条值得单独说。ABACUS 的预表化不是效率选择，而是切断了 β 对晶胞的导数链。所以"我们的应力 ≠ ABACUS 的应力"在某些体系上不是 bug，而是我们多了一项。这一点必须写进差异预算表，否则会陷入"追一个永远追不上的数"。

04已经在原型上踩到的四个真 bug

这四个都不是"语法错误"，而是能量看起来完全正确、梯度错了 20% 的那类。它们的价值在于：每一个都对应一条可执行的不变量，而那条不变量是事后才补上的。

#症状根因被哪条判据抓住
1力偏 20%，能量完全正确用了"显式泛函"形式（固定密度下对 ψ 不驻定），丢掉响应项驻点性 ∂E/∂n=0
2XC 势弱 8 倍，力偏 25%泛函导数漏 (Ω/N) 权重：jax.grad(E) 给的是偏导，物理势是泛函导数驻点性 + ΔE≈∫vδn
3两种能量形式差 0.046 HaV_NL 没进哈密顿量，而能量分解里又有它I-7 双形式一致
4势矩阵是垃圾，SCF 仍然"收敛"fftn 作用在扁平数组上（沿错轴）I-8 ⟨V⟩ = ∫v|ψ|²
5力偏 31%，ΣF=7.7e-2，能量只差 3 mHavg.astype(rho_r.dtype) 把 complex 静默转成 float，丢掉 n_G 的虚部，破坏 n(−G)=n(G)*v(ρ+δ)−v(ρ) = v(δ)
一个反直觉的结论（实测，不是推导）

在对称构型上，jax.jacfwd 穿过 eigh 会给出 1/(εₙ−εₘ) = 1/0 → AD 力全为 NaN，而有限差分给出 0。如果只看 FD，会得出"力是零，所以没问题"的错误结论。这就是 D4 级（简并子空间）的典型失败模式，也是本项目禁用"对本征值求导"的原因。

替代方案：解析一阶微扰 + 简并安全替换 (fₙ−fₘ)/(εₙ−εₘ) → f'(ε̄)。这不是数值技巧，而是占据加权密度矩阵在简并点的唯一连续延拓。

05校验方案：五级阶梯 + 五步协议

对齐不是一次动作，而是阶梯。每一级有明确的判据与失败含义，必须按顺序通过——跳过任何一级，后面的失败都无法归因。

级别对齐对象判据失败的含义
L0单元：每个原语 vs ref / 解析解逐元素 < 1e-10实现错误，与物理无关
L1解析极限：UEG、高斯 Hartree、Madelung能量 < 1 meV/atom公式或单位错
L2内部一致性：梯度 vs FD；不变量力 < 1e-4 eV/Å；应力 < 0.1 kbarVJP 错，或图被剪断
L3跨代码：vs ABACUS（同参数）能量 < 1 meV/atom；力 < 10 meV/Å约定不一致
L4物理标尺：EOS、声子、Born 电荷在已知误差内泛函/离散化不足（是选择，不是 bug）

把 L2（求导错）与 L3（约定错）混在一起调，是项目延期最常见的原因。

五步协议：顺序不能颠倒

  1. 算噪声地板δF ≈ δE/(2h) ≈ 0.13 meV/Å。任何小于它的项，FD 看不见——所以第一步必须先知道"能看见什么"。
  2. 项级消融每个能量项带 tag，自动跑"全开/逐个关/两两关"。得到每项量级，以及项与项的抵消结构（相消对）。
  3. 构型扫描平衡、±1% 应变、单原子位移 0.05 Å、低对称畸变，四个必须同时通过。补偿系数依赖构型，换构型就失效。
  4. 恒等式构型无关，因此优先级高于 FD：平移/旋转不变、ΣF=0、声学求和、驻点性、表示一致、响应一致。
  5. 交叉实现同一物理量两条独立路径：AD 伴随 vs 中心差分；显式泛函 vs 变分形式。同时错的概率远低于任一单独错。
反作弊七条（违反任一，加速比按 0 计）
1同精度：能量漂移 ≤0.1 meV/atom，残差 ≤1e-8

封存 oracle：唯一能对抗过拟合的机制

LLM 的稳定行为是"把测试通过当作目标"。因此测试必须部分隐藏，且隐藏部分的分布要与公开部分不同——按物理情形切分，不按随机切分。

公开集：绝缘体、平衡构型、单元素。封存集：金属、简并、极端形变、NLCC、多元素。每季度轮换 1/3；首次通过率 >90% 视为泄漏嫌疑。

08三件最先要做的事

  1. 写五份契约，一周内评审单位、离散化、赝势、占据、不变量。没有它，任务卡无法引用，对抗结构无法启动。
  2. 做 M0 判别实验，六周Si、Γ、LDA、20 Ry，三条求导路径，回答"隐式伴随是否成立"。这是唯一允许"先做再决定"的环节。
  3. 同时建两个 harness，而不是等有东西可比验证 harness 要能在已知错项上证明自己能抓错；性能 harness 要能在最小体系上跑七因子代理指标。它们验证的是"我们的验证有效"。

如果只能记住一句话：架构的价值不在于它看起来合理，而在于每一个设计决定都绑定了一条能被独立证伪的检验——并且这些检验已经抓到了四个真 bug，其中两个是"能量完全正确、梯度错 20%"的那种。
