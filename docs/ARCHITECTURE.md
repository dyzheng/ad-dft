# 自动微分周期性 DFT 内核 · 架构设计

> 版本 v0.1 · 基于 `abacus-develop`（develop 分支）源码实测 + DQC 的 AD 契约 +
> `可微DFT软件_ABACUS复刻方案_V2` 的方法论。
> 本文件描述**可执行的架构**与**已验证/未验证的边界**；未验证的部分不写成结论。

---

## 0. 一页结论

**做的是什么。** 不是"更快的 DFT"，而是一个**可微的周期性 DFT 内核**：能量是唯一
可微标量，力、应力、极化、Born 电荷、约束乘子都是它的导数；SCF 用不动点隐式微分，
显存与迭代数解耦。

**架构赌注（三条，每条都可被证伪）。**

1. **契约复刻，不复制代码。** ABACUS 的资产是"在特定约定下被验证十年的边界条件处理"，
   不是它的类设计。这些约定必须逐条写成 `spec/`，否则能量对上、梯度全错。
2. **可微边界只有一个：`Cell`。** 一旦晶格/分数坐标在 L1 被摊平成 numpy，
   后面所有导数都断，而能量仍然是对的。这是本项目最贵的错误类型，用类型系统挡住。
3. **力的正确性靠驻点性，不靠额外代码。** 若发现"必须为力写专门代码"，
   说明能量图里有东西没建对；这条本身就是架构健康度指标。

**已经在这份原型上踩到的四个真 bug**（全部记录在 §8，其中三个已修）：

| # | 症状 | 根因 | 被哪条不变量抓住 |
|---|---|---|---|
| 1 | 力偏 20% | 用"显式泛函"形式（固定密度下对 ψ 不驻定） | I-6 驻点性 |
| 2 | XC 势弱 8 倍，力偏 25% | 泛函导数漏 `N/Ω` 权重 | I-6 |
| 3 | 两种能量形式差 0.046 Ha | `V_NL` 没进哈密顿量 | I-7 |
| 4 | 势矩阵是垃圾 | `fftn` 作用在扁平数组（沿错轴） | I-8 |

**仍未通过的**：响应算子与 `scf_map` 的有限差分只达到 `corr=0.66 / rel=0.785`
（I-15）。这是唯一阻塞"力可发布"的缺陷，已写成任务卡 K12 的第一条验收门。

## 1. 复刻语义：三层，缺一不可

| 层次 | 含义 | 本项目的处理 |
|---|---|---|
| **契约复刻** | 物理量、离散化、单位、边界条件逐条对齐 | `spec/` 五份文件，评审签字后冻结 |
| **架构借鉴** | 借执行骨架与模块边界，重写实现 | 见 §3 的 L0–L5 与 §7 的映射表 |
| **不做代码复刻** | 不照搬类层次与文件组织 | 明确拒绝：会把历史包袱一起继承 |

判断标准很具体：**如果新代码换了一套"等价但不同"的约定，能量误差可能是 1e-5 Ha，
而力误差是 1e-2 eV/Å —— 正好是"能不能做结构优化"的分界。**
所以契约必须先锁定，再谈求导。

## 2. 从真实 ABACUS 代码里挖出的九条硬约定

这一节是本文档最有价值的部分：它把"方案文档的假设"换成"源码的事实"。
`docs/ABACUS_FACTS.md` 收录了逐条文件路径，此处只列结论与差异。

| # | 事实 | 与方案文档的差异 | 对架构的影响 |
|---|---|---|---|
| 1 | **内部单位是 Ry–Bohr**：`e2=2`，动能算符无 ½ | 方案按 Ha 写公式 | 单位桥必须在 adapter 层，见 `spec/units.md` |
| 2 | FFT 盒：奇数 → **只含 2,3,5**（7 被注释掉） | 方案说"2,3,5 平滑数"，对 | 直接复用规则 |
| 3 | 密度网格 `ecutrho = 4×ecutwfc`，wfc 复用同一盒 | 未提 | 默认 `density_factor=4` |
| 4 | **NLCC 被读取但从不参与 XC** | 方案说 NLCC 会造成 1–5 meV 差异 | 必须显式选择：实现或拒绝，不许静默 |
| 5 | β(\|k+G\|) **预表化**（`dq=0.01`，4 点插值） | 方案警告过，但没确认 ABACUS 真这么做 | 本项目**不做**预表化（这是 AD 的立足点） |
| 6 | `D_ij` 0-based，`l²+m` 展平；`ijtoh` 残留 1-based | 未提 | UPF 解析必须有逐元素测试 |
| 7 | SCF 判据是**归一化密度残差**，非能量差 | 方案提到，一致 | 复用 `drho` 定义 |
| 8 | μ 用**纯二分**，σ 单位 **Ry** | 方案说 Newton | 二分更稳；单位统一到 Ha |
| 9 | 解析力分 5 项（loc/nl/onsite/cc/scc），应力 10 项 | 方案说"AD 自动" | 这是**对照物**：我们的 AD 必须能逐项对上 |

第 5 条值得单独说：ABACUS 预表化不是"效率选择"，而是"切断了 β 对晶胞的导数链"。
我们的应力要与 ABACUS 对比时，必须知道对方在这一项上是**不完备**的——
所以"我们的应力 ≠ ABACUS 的应力"在某些体系上不是 bug，而是我们多了一项。

## 3. 分层架构

```
              ┌──────────────────────────────────────────────┐
   L6 应用    │ 泛函训练 · Δ-learning · 约束扫描 · 逆设计      │  不反向依赖实现
              └──────────────────┬───────────────────────────┘
              ┌──────────────────┴───────────────────────────┐
   L5 观测量  │ E(分解) · F · σ · P(Wilson) · Z* · λ(约束)    │  薄：>50 行说明在重实现 L2
              └──────────────────┬───────────────────────────┘
              ┌──────────────────┴───────────────────────────┐
   L4 微分层  │ ① 局部 VJP  ② 不动点隐式  ③ 变分端到端        │  只在收敛点调用
              └──────────────────┬───────────────────────────┘
              ┌──────────────────┴───────────────────────────┐
   L3 求解器  │ SCF 不动点 · 混合器 · 本征求解 · 响应算子      │  唯一允许有迭代的层
              └──────────────────┬───────────────────────────┘
              ┌──────────────────┴───────────────────────────┐
   L2 物理原语│ 密度 · Hartree · XC(energy-only) · V_NL ·     │  每个原语：fwd + vjp + 梯度测试
              │ Ewald · 占据数 · 局域势                       │
              └──────────────────┬───────────────────────────┘
              ┌──────────────────┴───────────────────────────┐
   L1 几何基组│ Cell(pytree 叶子) · Basis(冻结壳层) ·         │  全项目最重要的可微接口
              │ KMesh(权重和为 1) · Pseudo(径向可微)          │
              └──────────────────┬───────────────────────────┘
              ┌──────────────────┴───────────────────────────┐
   L0 运行时  │ 单位 · dtype · 精度账本 · 设备/shmap          │  不做物理
              └──────────────────────────────────────────────┘
```

**跨层判据**：`L4` 只依赖"收敛后的状态"，不依赖迭代历史。如果看到 L4 调用
`mixer`，立即拒绝——那是把"梯度是否可信"与"混合器调得好不好"耦合在一起。

### 数据流（一次能量/梯度）

```
STRU/KPT/INPUT ──(adapter)──► Cell + Static
                              │
                              ├─► L1: miller(冻结) · g2(cell) · fft_shape · β(q;R,cell)
                              ├─► L2: ψ → n → (V_H, V_xc, V_NL) → H(k)
                              ├─► L3: eigh / Davidson → ψ*, occ*, μ*
                              ├─► L4: [仅收敛点] A = I − ∂F/∂n;  Aᵀλ = ∂L/∂n
                              └─► L5: E, F = −dE/dR, σ = (1/Ω)dE/dε, P, Z*, λ
```

## 4. 类型系统：可微边界必须写在类型里

```python
class Cell(NamedTuple):          # ← 唯一的可微叶子
    lattice: Array               # (3,3) 行向量 a_i, Bohr
    frac:    Array               # (nat,3) 分数坐标

class Static(NamedTuple):        # ← 一律不进微分图
    basis: Basis                 # miller 冻结、fft_shape 冻结
    kpts, kweights               # 权重和为 1
    psp: Pseudo                  # 赝势数值
    spec_idx, nband, sigma, nelec, spin_degeneracy
```

三个理由，都不是洁癖：

1. **显存**：把 `Static` 拖进图里，`vmap` 扫应变时会复制全部赝势表。
2. **无意义的导数**：`∂E/∂nband` 是什么？没人想知道，但 AD 会算给你，并且算错。
3. **接口冻结**：`Static` 是不可变 NamedTuple，任何"偷偷改字段"都会在 pytree
   展平处报错。

`Basis.miller` 是 `int32` 数组：它在参考构型上一次生成，之后**不随几何变化**。
物理 G 矢量每次都从 `lattice` 重算，因此 Pulay 项自动进入图。

## 5. 微分层的三个接口

| 接口 | 数学结构 | 实现 | 何时用 |
|---|---|---|---|
| ① 局部 VJP | 线性/逐点算子 | `jax.custom_vjp`，VJP = 伴随算子 | XC、V_NL、FFT、Poisson |
| ② 不动点隐式 | `n* = F(n*;θ)` | `Aᵀλ = ∂L/∂n`，`A = I−∂F/∂n` | SCF 收敛点的一切导数 |
| ③ 变分端到端 | `min_ψ E[ψ]` | 直接 `jax.grad` | 泛函训练、NN-VMC 支线 |

三条路径的关系：①是构件，②是生产主路径，③语义最干净但条件数最差。

### 5.1 为什么响应算子不用 `jacfwd(scf_map)`

`jax.jacfwd` 穿过 `eigh` 会在简并处给出 `1/(ε_n−ε_m) = 1/0`。
本仓库实测：对称二聚构型上 AD 力**全为 NaN**，而有限差分给出 0——
如果只看 FD，会得出"力是零，所以没问题"的错误结论。

因此响应算子改为**解析一阶微扰**：

```
δv_eff = K_H δn + K_xc δn
δH     = vmat(δv_eff)
M      = C† δH C
δc_n   = Σ_{m≠n} c_m · M_mn/(ε_n − ε_m)      ← 简并处 → f'(ε̄)
δf_n   = f'(ε_n)(δε_n − δμ),  δμ = Σ w f' δε / Σ w f'
δρ     = Σ_n w g_s [ f_n · 2Re(ψ_n* δψ_n) + δf_n |ψ_n|² ]
```

三个口径必须与 `scf_map` **逐字一致**，否则 I-15 失败：
本征态截断（保留几个态）、占据数口径（μ 从哪个谱求）、表示口径（谱式/网格）。

### 5.2 包络定理与"力不需要专门代码"的准确表述

在收敛点，KS 变分泛函 `E[ψ]` 对 ψ 驻定，因此

```
dE/dθ = ∂E/∂θ |_(ψ 冻结)                  （一阶导不需要响应项）
```

推论：**$\partial E/\partial R$ 与 $\partial E/\partial \varepsilon$ 都可以在"状态冻结"
的前提下由 AD 直接给出**，三项 Pulay（G 缩放、Ω、β 随几何重建）自动出现。

但这条结论有三处必须限定，否则会误用：

1. **只对变分形式成立。** 用"显式泛函"（`T + ∫v_loc n + E_H + E_xc + E_NL + E_II`）
   时，固定 n 下对 ψ 不驻定，丢掉响应项会带来 20% 的力偏差（实测）。
2. **只对能量成立。** 非能量观测量（`∫w·n` 的 DeltaQ 约束值、极化、Born 电荷）
   `λ ≠ 0`，响应项是必需的。
3. **只在一阶成立。** 二阶（声子、弹性常数）必须显式求响应。

所以架构上保留完整的隐式微分通路，而不是"既然 λ≈0 就删掉"——
它是**其它一切观测量**的基础，也是"如果能量形式写错，它能自动补回来"的保险。

## 6. 表示一致性：本项目最贵的一条工程约束

同一个物理量有两种离散表示：

* **谱式/矩阵**：`V_GG' = ṽ(G−G')`，期望 `Σ c* V c`
* **实空间**：`(Ω/N) Σ_j v_j |ψ_j|²`

当 `V` 非带限时（`v_xc` 是 `n` 的逐点非线性函数，含到 Nyquist 的频率），
两者**不相等**，差值就是 `v·|ψ|²` 超出网格 Nyquist 的混叠项。实测：
同一 `v` 的两种表示差 34%。

约定：**一体项一律谱式，二体/密度泛函一律网格**，并在 `contract-check` 里检查。

这条约束的代价是网格必须满足 `π n/L > 3|G|_max`（若混用）。它的收益是：
能量对密度严格驻定（I-6 通过），力与有限差分一致。

## 8. 已知缺口（诚实清单）

### 8.1 已修复（五个，每个都曾是"能量对、梯度错"）

| # | 缺陷 | 症状 | 根因 | 抓到它的判据 |
|---|---|---|---|---|
| 1 | 显式泛函形式 | 力偏 20% | 固定 ρ 下对 ψ 不驻定，丢掉响应项 | 驻点性 |
| 2 | 泛函导数漏 `N/Ω` | XC 势弱 8×，力偏 25% | `jax.grad(E)` 是偏导，物理势是泛函导数 | 点级 XC oracle |
| 3 | `V_NL` 未进 H | 两种能量形式差 0.046 Ha | H 少了非局域项，能量分解里有 | I-7 双形式一致 |
| 4 | `fftn` 作用在扁平数组 | 势矩阵是垃圾，SCF 仍"收敛" | 少了 `reshape(fft_shape)` | 手算 ⟨V⟩ |
| 5 | **`complex → float` 静默转换** | 力偏 31%，ΣF=7.7e-2 | `vg.astype(rho_r.dtype)` 丢掉 `n_G` 的虚部，破坏 `n(-G)=n(G)*`，Hartree 势等价于"密度先对称化" | v(ρ+δ)−v(ρ) ≠ v(δ)（线性性偏差 21%） |

第 5 个是最贵的一个：SCF 照样收敛、总能只差几 mHa、FC 全绿，
但整条梯度链与所有"能量形式之间"的恒等式同时失效。它的检测成本极低
（一次线性性检查），发现成本极高（三小时的人肉二分）。

### 8.2 本轮已关闭（R3-01）

| # | 原症状 | 根因 | 修复 |
|---|---|---|---|
| 6/7 | ⟨ψ|V|ψ⟩ 与网格积分差 30%，∫|ψ|² 不自洽 | 测试把 `psi_to_real(...)[0]` 截成标量 | 去掉 `[0]`；实测 ∫|ψ|²=1.0 |
| 8 | 稠密 V_NL 非 Hermitian（1.3e-3） | `dion_full` 用错 4D 布局，块被交错 | 改成 `(i,p,j,q)` 后 D 严格 Hermitian |

### 8.3 功能范围（按 V0 设计，不是缺陷）

无 k 点（仅 Γ）、无自旋、无 NLCC、稠密 `eigh`（`nG < 2000`）、
响应算子展开成稠密矩阵（`nfft > 3000` 不可行）、无 UPF 解析（用合成赝势）。
对应任务卡 K03/K05/K09/K10/K12。

### 8.4 当前实测（ecut=2 Ha，nG=27，nfft=729，低对称构型）

| 量 | 值 |
|---|---|
| 总能 | −2.5348 Ha |
| SCF | 73 步，残差 2.0e-13 |
| I-7 双能量形式 | 0（机器精度） |
| I-8 响应算子 vs `scf_map` FD | corr 1.0000，rel 6.7e-9 |
| I-10 `ΣF` | 4.2e-8 Ha/Bohr |
| 力 vs FD（h=1e-3） | gap 5.7e-7 Ha/Bohr ≈ 3e-5 eV/Å |
| 力 vs Richardson 外推 | gap 3.1e-12 |
| FD 残差 h 标度 | 8e-3→1e-3 时 3.66e-5→5.73e-7（∝h²） |

**结论：能量层与梯度层都已可用（原型规模）。** 剩下的是范围与三项诊断缺口。

## 9. 与 DQC 的关系：继承什么、拒绝什么

DQC 证明了一件事：一个真实的、可微的量子化学代码长什么样。它的 AD 契约值得
整套继承：原语 VJP、`energy-only` XC（`CustomXC.get_edensityxc` 只给能量密度）、
`equilibrium` 风格的不动点求解（`xitorch.optimize.equilibrium`）、gradcheck 文化。

必须拒绝的是它的**物理栈**：GTO 基组 + 双中心积分 + 非正交基。
本项目是平面波 + 周期性，导数链短得多。

最有价值的一条教训来自它的 PBC 分支：

```python
# dqc/hamilton/intor/gtoft.py:70
def backward(ctx, grad_res):
    raise NotImplementedError("gradients of GTO FT evals are not implemented")
```

**前向能算、反向抛异常的模块，不允许进入主干。** 因此本项目规定：

> 每个原语在合入 `main` 前，必须同时提交 `fwd`、`vjp`、以及一个能自动跑的
> 梯度测试。没有 VJP 的原语只能存在于 `sandbox/`，不能出现在 `physics/` 里。

这条规则在 CI 里是可执行的：`physics/` 下每个公开函数必须有对应的
`tests/test_<name>.py::test_vjp`，否则 `pytest --collect-only` 报缺失。

```
│   │                         #     ewald, occupation, response(线性化)
│   ├── solver/               # L3: eigh(子空间不变), mixer(DIIS), scf
│   ├── diff/                 # L4: implicit(不动点隐式微分)
│   ├── observables/          # L5: energy(带 tag 的分解 + 变分形式)
│   ├── system.py             # Static / SCFState（可微边界）
│   └── api.py                # 对外唯一入口
├── ref/                      # float64 参考实现（最笨的写法）
├── tests/                    # oracle / invariance / fd / contracts
├── bench/                    # 七因子 harness
├── adapters/abacus/          # STRU/KPT/INPUT 适配 + regress CLI
└── docs/                     # ARCHITECTURE / TASKS / VALIDATION / ABACUS_FACTS
```

## 11. 一句话

架构的价值不在于它"看起来合理"，而在于**每一个设计决定都绑定了一条能被独立
证伪的检验**，并且这些检验已经抓到了四个真 bug——其中两个是"能量完全正确、
梯度错 20%"的那种。这才是可微 DFT 与"给 DFT 加个 autograd"的区别。
