# 校验方案

> 验收哲学一句话：**能量对齐是入场券，梯度对齐是毕业证；对高阶相消，
> 恒等式才是学位论文。**
> 本文件的所有判据都可在 `tests/` 里执行，所有门槛都写死、不允许在调用点覆盖。

---

## 1. 五级对齐阶梯

必须按顺序通过。跳过任何一级，后面的失败都无法归因。

| 级别 | 对齐对象 | 判据 | 失败的含义 |
|---|---|---|---|
| **L0** 单元 | 每个原语 vs ref / 解析解 | 逐元素 < 1e-10（fp64） | 实现错误，与物理无关 |
| **L1** 解析极限 | UEG、高斯 Hartree、Madelung、单原子散射 | 能量 < 1 meV/atom | 公式或单位错 |
| **L2** 内部一致性 | 梯度 vs FD；不变量 I-6..I-15 | 力 < 1e-4 eV/Å；应力 < 0.1 kbar | VJP 错，或图被剪断 |
| **L3** 跨代码 | vs ABACUS（同参数） | 能量 < 1 meV/atom；力 < 10 meV/Å | 约定不一致 |
| **L4** 物理标尺 | EOS、声子、Born 电荷、带隙 | 在已知误差内 | 泛函/离散化不足（不是 bug） |
| **L5** 回归套件 | 固定算例集 | 全过且漂移 < 1e-5 | 回归 |

**关键性质：失败的可归因性。** L0 失败 = 代码错；L2 失败 = 求导错；
L3 失败 = 约定错；L4 失败 = 物理模型不够（这是选择，不是缺陷）。
把三类混在一起调，是项目延期最常见的原因。

### 1.1 每一级的可执行判据

```
L0  pytest tests/test_primitives.py -q
    ↳ 每个原语：kernel vs ref 逐元素；jax vs ref；vjp vs FD 二阶收敛

L1  pytest tests/test_oracles.py -q
    ↳ UEG 能量 < 1e-6 相对；高斯 V_H < 1e-8；Ewald η 无关性 < 1e-8

L2  pytest tests/test_invariance.py tests/test_forces.py -q
    ↳ I-6 驻点性；I-7 两种能量形式；I-10 ΣF=0；I-15 响应算子；
      力 vs 四构型中心差分

L3  dtf regress --case si-gamma --against abacus
    ↳ 固定七项（见 §4），输出 ΔE / ΔF / Δσ + 收敛曲线

L4  dtf bench --suite eos,phonon,born
    ↳ 与实验/DFPT 对比，落在材料学已知误差内

L5  dtf regress --all --baseline .dtf/baseline.json
    ↳ 与上次基线逐项对比，漂移 < 1e-5
```

## 2. 五步验证协议（按顺序，不能颠倒）

### 第一步：算噪声地板

中心差分的力噪声 `δF ≈ δE_scf/(2h)`。取 `δE = 1e-8 Ha`、`h = 1e-3 Bohr`：

```
δF ≈ 5e-6 Ha/Bohr ≈ 0.13 meV/Å
```

**推论：任何小于 0.1 meV/Å 的项，FD 看不见。** 如果某推导错误的量级恰好落在
这个区间，FD 会给它"通过"。所以第一步必须先知道"能看见什么"。

### 第二步：项级消融

每个能量项带 tag（`energy_terms(..., active={...})`），harness 自动跑
"全开 / 逐个关 / 两两关"，输出贡献矩阵：

* 每一项的量级（判断是否在噪声地板以下）；
* 项与项的**抵消结构**（哪些项一开一关总账几乎不变 → 这些是"相消对"）。

`n ≈ 7` 项时约 50 次单点评估，小体系可接受。

### 第三步：构型扫描

单一构型的 FD 通过不算数。至少四个构型：

1. 平衡构型
2. ±1% 单轴应变
3. 一个原子位移 0.05 Å
4. 低对称畸变（破坏所有对称性）

四个必须**同时**通过，误差上界一致。理由：抵消错误的"补偿系数"依赖构型，
换构型立刻失效。

### 第四步：恒等式（最强判据）

构型无关，因此优先级高于 FD。最小集合：

| 恒等式 | 形式 | 抓住什么 |
|---|---|---|
| 平移不变 | `E(R+δ)=E(R)`，`Σ_I F_I=0` | 基组随原子移动的项 |
| 旋转/置换不变 | `E(QR)=E(R)` | 张量指标错误 |
| 声学求和 | `Σ_I Z*_{I,αβ}=0` | 规范、Pulay 项遗漏 |
| 驻点性 | `∂E/∂n|_ψ = 0` | 泛函导数权重、表示混用 |
| 表示一致 | `⟨ψ|V|ψ⟩ = (Ω/N)Σv|ψ|²` | FFT 轴、归一化 |
| 响应一致 | `J·δ = dF/dn·δ` | 线性化的对象是否就是正向的映射 |
| 极限退化 | `S→I` 回 PW 公式；`δR→0` 回解析力 | 项结构错误 |

### 第五步：交叉实现

同一物理量用两条独立路径算：

* 力：AD 隐式伴随 vs 中心差分（重跑 SCF）
* 能量：显式泛函分解 vs 变分形式
* 极化：Wilson 环 vs 有限位移 DFPT

两条路径共享的能量图必须一致，但求导机制不同。它们同时错的概率远低于任一单独错。

## 3. 反作弊七条（写进 CI，违反任一条的结果不计入）

1. **同精度**：能量漂移 ≤ 0.1 meV/atom，力漂移 ≤ 1 meV/Å，应力漂移 ≤ 0.1 kbar，
   SCF 残差 ≤ 1e-8。任一超限，加速比按 **0** 计。
2. **同输入**：赝势 sha256、libxc ID、`ecut`、k 网格逐项一致，写进报告头。
3. **端到端计数**：进程启动 → 结果落盘，含初始化、I/O、Python 调度。
   禁止只报 kernel 时间。
4. **冷/热分开**：冷启动（无波函数初猜）与热启动分别报告；不许用热启动对冷启动 baseline。
5. **统计**：5 次中位数 + 四分位距；禁止删点；`IQR/中位数 > 15%` 先修测量。
6. **归因**：任何 > 10% 的加速必须附"因子归因"（开关实验或 profiler）。
   归因不出来的加速视为测量噪声。
7. **近似模式**：任何低秩/截断/稀疏化近似，必须在精度报告里**打开同一开关**；
   不许"benchmark 时关、生产时开"。

这七条的作用不是限制，而是让优化工作有一个**不可伪造的记分牌**。

## 4. L3 对比规程：必须固定的七项

任何一项没固定，结果就没有意义。写成 YAML 模板，harness 自动检查。

```yaml
# tests/regress/si-gamma.yaml
system:  si-diamond-2atom
pseudo:  Si_ONCV_PBE-1.0.upf
pseudo_sha256: "…"          # 1. 同一个文件
xc_libxc: [XC_GGA_X_PBE, XC_GGA_C_PBE]   # 2. libxc ID，不是 "PBE" 字符串
ecut:    30.0               # 3. Ry；两边壳层构造规则一致
kmesh:   gamma              # 4. 同 Monkhorst-Pack 位移
symmetry: 0                 # 5. 关闭 IBZ 约化（IBZ 引入不可控权重差异）
smearing: {method: none, sigma: 0.0}     # 6. 同方法同 σ 同单位
scf_thr: 1.0e-8             # 7. 报告实际残差
```

输出必须包含四个数：`ΔE`（meV/atom）、`ΔF_max`（meV/Å）、`Δσ`（kbar）、
以及"偏差在改 `ecut` / `nfft` 时是否系统性漂移"。前三个是静态判据，
第四个是**归因判据**：

* 随截断能单调收敛 → 离散化差异，可接受；
* 不随任何参数收敛 → 约定差异，必须修。

## 5. 差异预算表

| 来源 | 典型量级 | 可控性 | 如何确认 |
|---|---|---|---|
| libxc 版本 | < 0.1 meV/atom | 完全 | 锁版本，逐点比 `v_xc` |
| XC 网格规则 | 0.1–1 meV/atom | 高 | 扫 `ecut`，看是否收敛 |
| 平面波截断 | 1–10 meV/atom | 完全 | 两边同 ecut + 同壳层规则 |
| 赝势解析（NLCC、D 索引） | 1–5 meV/atom；力可达 50 meV/Å | 完全 | 逐元素比 β、D、ρ_core |
| **NLCC 是否参与 XC** | 1–5 meV/atom | 完全 | 报告头标 `nlcc=on/off` |
| smearing 方案与 σ | 1–10 meV/atom（金属） | 完全 | 同 σ，比较 F 而非 E |
| k 网格与对称性约化 | < 0.1 meV/atom | 高 | 用全网格对比一次 |
| SCF 阈值 | 0.1–1 meV/atom | 完全 | 扫 `scf_thr`，看能量平台 |
| Ewald 参数与截断 | < 0.1 meV/atom | 完全 | 扫 η 与实空间截断 |
| 自旋初猜（磁性） | 可达 10 meV/atom | 低 | 同初猜，检查磁矩 |

用法：先报总偏差，再报"按表逐项消减后的残差"。残差不为零 = 有一项没被预算覆盖
= 真 bug 或未文档化的约定。

## 6. 封存 oracle：唯一能对抗过拟合的机制

LLM 的稳定行为是"把测试通过当作目标"。因此测试必须部分隐藏，
且隐藏部分的**分布要与公开部分不同**（按物理情形切分，不按随机切分）。

| 规则 | 内容 |
|---|---|
| 按情形切分 | 公开集：绝缘体、平衡构型、单元素；封存集：金属、简并、极端形变、NLCC、多元素 |
| 每条都有物理理由 | 不是"再随便取一个"，而是"这一条针对某个已知失败模式" |
| 季度轮换 1/3 | 防止通过反复提交试探出边界 |
| 泄漏检测 | 首次通过率 > 90% 视为泄漏嫌疑，人工审计 |
| 物理隔离 | 封存集不进仓库，只在独立评测服务跑 |

### 8.2 读法

18 项内部判据全部通过。此前三项“诊断项”已由 R3-01 的 `dion_full` 布局与测试
辅助函数修正，当前实测：矩阵/网格差 2.08e-17、V_NL 转置差 4.47e-18、

### 8.3 slow 门禁的运行方式

三个门禁（力 vs FD、h² 标度、ΔQ 伴随）每次都要 4–8 次 SCF，单进程连续跑会
让 XLA 编译缓存累积到 GB 级。因此：

```bash
# 默认（快）：每文件 < 2 min
bash run_tests.sh

# slow 门禁：一次只跑一个，在独立进程里
pytest tests/test_forces.py -m slow -k test_forces_vs_finite_difference -o addopts=""
```

已记录的 slow 结果：力 vs FD gap 5.66e-7 Ha/Bohr；h² ratio 4.0；ΔQ 伴随残差
2.28e-11，vs 重跑 SCF FD 相对误差 1.65e-5。

### 8.4 这条记录本身的价值

它把"看起来能跑"的代码挡在了"可以发布"之外，并且在三个小时里定位了
**五个**"能量完全正确、梯度错 20–31%"的 bug。最后一个是
`vg.astype(rho_r.dtype)` —— 一行把 complex 静默转成 float 的代码，
丢掉了 `n_G` 的虚部，破坏 `n(-G)=n(G)*`，使 Hartree 势等价于
"密度先对称化再求势"。SCF 照样收敛，FC 全绿，而整条梯度链是错的。

检测它只需要一条判据：**v(ρ+δ) − v(ρ) 是否严格等于 v(δ)**。

## 9. 三件必须最先做的事

1. **写五份契约**（一周内评审）。没有它，任务卡无法引用，对抗结构无法启动。
2. **做 M0 判别实验**（六周）：Si、Γ、LDA、20 Ry、三条求导路径，
   回答"隐式伴随是否成立"。

   性能 harness 要能在最小体系上跑七因子代理指标。

三件事都不需要 GPU。
