# 契约 4：占据数与 Mermin 自由能

## 1. 与 ABACUS 的对齐点

| 项目 | ABACUS 事实 | 来源 |
|---|---|---|
| 方法 | `gauss` / `mp`(n=1,2) / `mv,cold` / `fd` | `occupy.cpp:95-132` |
| μ 求解 | **纯二分**，`maxiter=300`，容差 `16·eps·max(1,N_e)` | `occupy.cpp:394-464` |
| σ 单位 | **Ry**，默认 0.015；无换算 | `input_parameter.h:107-108` |
| 自由能 | `F = E − T·S`，`S = −k_B Σ w[f ln f + (1−f)ln(1−f)]` | `fp_energy.cpp` |
| 收敛判据 | `drho < scf_thr`（归一化密度残差，非能量差） | `chg_routine.cpp:45`、`chg_drho.cpp:14-85` |

## 2. 三条硬规则

1. **力必须来自 F，不是 E。** 用 E 求力的误差是 `−T ∂S/∂R`，σ=0.1 eV 时可达
   几十 meV/Å，且符号系统，会让结构优化偏向熵增方向。
2. **μ 是标量隐式变量**，导数
   `dμ/dθ = −(Σ w f' dε/dθ)/(Σ w f')`。漏掉它，电子数不守恒，
   能量对晶胞的导数在 σ 较大时明显偏离有限差分。
3. **σ → 0 不是极限操作。** `∂f/∂ε` 分母趋零；金属低温必须走整数占据分支
   （`_integer_occupation`），简并时取平均占据。

## 3. 离散化选择

* μ 用固定步数二分（`lax.fori_loop`，80 步）→ 可前向自动微分，且无动态 shape。
* 占据数的截断谱与 `scf_map` 的截断一致：只用最低 `nband` 个本征值。
  响应算子必须**同口径**（见 `physics/response.py` 的注释）。
* 自旋简并因子 `g_s` 只出现在密度与能量里，**绝不**进 `w_k`。

## 4. 验收

| 检查 | 门槛 |
|---|---|
| 电子数守恒 `|Σ w f g_s − N_e|` | < 1e-10（任意扰动下） |
| σ 扫描 `σ → 0` | F 连续趋于绝缘体 E，无跳变 |
| 金属力 vs FD | < 5e-3 eV/Å（σ=0.1 eV；金属基线比绝缘体差是物理的） |
| μ 的导数 vs FD | 相对误差 < 1e-6 |

## 5. 失败模式

* **F-O1**：用 E 求力（最常见）。
* **F-O2**：σ 单位混用（eV/Ry/Ha）。
* **F-O3**：自旋因子 2 漏乘或重乘（能量差 2×，力却对）。
* **F-O4**：二分容差过松 → 梯度有噪声，表现为"力随 σ 抖动"。
