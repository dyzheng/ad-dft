# 契约 5：不变量与"什么算通过"

> 本文件是全项目的宪法：所有验收判据都可归约到这里的一条。
> 每条不变量必须写成**构型无关**的测试（对任意结构成立），而不是单点巧合。

## A. 解析极限

| 编号 | 不变量 | 判据 | 抓住什么 |
|---|---|---|---|
| I-1 | 均匀电子气（UEG） | LDA 能量 vs 解析拟合 < 1e-6 相对；应力 = −P | 单位、`1/√Ω`、Nyquist 重复计数 |
| I-2 | 高斯电荷 Hartree | `V_H(r)` vs 解析 `erf(√α r)/r` < 1e-8 | G=0 处置、1/Ω 次数 |
| I-3 | 单原子散射相移 | β、D 与 ABACUS 逐元素 < 1e-10 | UPF 索引与展平顺序 |
| I-4 | Madelung 常数 | NaCl `1.7475645946` | Ewald 自能/背景项配对 |
| I-5 | 类氢极限 | 能量与 1s 解析值一致 | 动能算符系数（½ 与 Ry/Ha） |

## B. 内部一致性（梯度门禁的核心）

| 编号 | 不变量 | 判据 |
|---|---|---|
| I-6 | **驻点性** `∂E/∂n|_ψ = 0` | 范数 < 1e-8·‖v_eff‖，在收敛点 |
| I-7 | 两种能量形式相等 | 显式泛函 vs 变分形式，差 < 1e-12 |
| I-8 | 矩阵期望 = 网格积分 | `⟨ψ|V|ψ⟩` vs `(Ω/N)Σv|ψ|²`，差 < 1e-12（同一表示下） |
| I-9 | 伴随恒等式 | `⟨Ax,y⟩ = ⟨x,A^Ty⟩` 到机器精度 |
| I-10 | 平移不变 | `E(R+δ) = E(R)`；`Σ_I F_I = 0` 到 1e-8 |
| I-11 | 旋转/置换不变 | `E(QR) = E(R)`；同种原子置换不变 |
| I-12 | 声学求和规则 | `Σ_I Z*_{I,αβ} = 0` |
| I-13 | 电子数守恒 | `|Σ w f g_s − N_e| < 1e-10` |
| I-14 | 壳层跳变 | 应力不连续 < 0.1 kbar |
| I-15 | 响应算子 = 物理映射的导数 | `J·δ` vs `(F(n+hδ)−F(n−hδ))/2h`，corr > 0.999 |

I-15 是本项目**最容易漏**的一条：它不检验物理，只检验"你线性化的对象是不是
正向真正执行的那个映射"。截断口径（保留几个本征态）、占据数口径
（μ 从哪个谱求）、表示口径（谱式还是网格）任何一处不一致，它都会失败。

## C. 子空间规则（D4 级）

> 微分层只接受「子空间不变」的输出：总能量、密度矩阵、投影算子。

* 任何对单个本征值的求导请求必须**抛异常**（`solver/eigh.py: forbidden`），
  不允许返回 NaN。理由是 NaN 会被误读成"体系病态"。
* 简并处 `(f_n−f_m)/(ε_n−ε_m) → f'(ε̄)`。这不是数值技巧，是占据加权密度矩阵
  在简并点的唯一连续延拓。
* 显式禁用的路径：`jax.jacfwd`/`jacrev` 穿过 `eigh`（会在简并处返回 NaN 或巨大值）。
  本仓库实测：二聚体对称构型上 AD 力全为 NaN，而有限差分给出 0——
  只看 FD 会以为"力是零，所以没问题"。

## D. 数值噪声地板

中心差分的力噪声：

```
δF ≈ δE_scf / (2h)
δE = 1e-8 Ha, h = 1e-3 Bohr  ⇒  δF ≈ 5e-6 Ha/Bohr ≈ 0.13 meV/Å
```

推论：**任何小于 0.1 meV/Å 的项，有限差分看不见。**
若某个推导错误的量级正好落在这个区间，FD 会给它"通过"。
因此对高阶相消的推导，恒等式的优先级高于 FD。

## E. 允许的差异（差异预算，不是 bug）

| 来源 | 典型量级 | 可控性 |
|---|---|---|
| libxc 版本 | < 0.1 meV/atom | 完全（锁版本） |
| XC 网格规则 | 0.1–1 meV/atom | 高（同规则） |
| 平面波截断 | 1–10 meV/atom | 完全（同 ecut） |
| 赝势解析（NLCC/D 索引） | 1–5 meV/atom；力可达 50 meV/Å | 完全 |
| smearing 方案与 σ | 1–10 meV/atom（金属） | 完全 |
| SCF 阈值 | 0.1–1 meV/atom | 完全 |
| 自旋初猜（磁性） | 可达 10 meV/atom | 低 |

任何超出预算的偏差必须归因到某一行，否则不允许进入下一阶段。
